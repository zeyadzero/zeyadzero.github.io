# assets folders (where your files go)

| Folder | What to put there | Used by |
|---|---|---|
| `photo/` | your portrait, square ~600x600 (`me.jpg`) | profile photo |
| `projects/` | project screenshots, 16:9 (`my-project.png`) | image on top of each project |
| `certs/` | certificate images or PDFs | courses and official certificates |
| `cv/` | your CV files (PDF) | CV section |
| `gallery/` | event / talk / hackathon photos | gallery |
| `companies/` | company logos | experience |
| `samples/` | generated SAMPLE art and CVs | delete after you add your own |

Then write the path in the editor (e.g. `assets/photo/me.jpg`) - or let the editor's
"Update pack (ZIP)" place the files for you.
